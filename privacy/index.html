Политика конфиденциальности
Cat-Bot

Дата последнего обновления: 23.09.2026
Настоящая Политика является неотъемлемой частью Условий использования и Правил использования Cat-Bot, и дополняет их.

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие данные собирает Discord-бот Cat-Bot (далее — «Бот»), как они используются и хранятся.

1.2. Используя Бота, Пользователь подтверждает согласие с настоящей Политикой.

1.3. Разработчик вправе изменять Политику в одностороннем порядке.

2. Какие данные собираются

2.1. Бот собирает следующие данные о пользователях:

  • ID пользователя — уникальный идентификатор в Discord;
  • Имя пользователя (username);
  • Аватар пользователя.

2.2. Бот собирает следующие данные о серверах:

  • ID сервера — уникальный идентификатор сервера в Discord;
  • Название сервера;
  • Иконка сервера.

2.3. Бот не собирает:

  • содержание сообщений;
  • личные сообщения;
  • данные о голосовых каналах;
  • email, номер телефона или иные контактные данные;
  • платёжную информацию.

3. Зачем собираются данные

3.1. Данные пользователей (ID, имя, аватар) используются исключительно для:

  • идентификации пользователя при работе команд Бота;
  • отображения информации о пользователе (например, в профиле, рейтинге, экономике);
  • корректной работы экономической системы и системы уровней.

3.2. Данные серверов (ID, название, иконка) используются исключительно для:

  • идентификации сервера при работе команд Бота;
  • отображения информации о сервере (например, в информации о сервере);
  • корректной работы функций, привязанных к серверу.

3.3. Данные не используются для рекламы, аналитики, профилирования или передачи третьим лицам.

4. Как хранятся данные

4.1. Бот хранит только ID пользователей и серверов. Имена, аватары, названия и иконки серверов не сохраняются в базе данных Бота — они запрашиваются у Discord в момент использования и не хранятся постоянно.

4.2. Данные хранятся на серверах, используемых Разработчиком для работы Бота.

4.3. Данные хранятся в течение срока, необходимого для работы Бота, либо до момента их удаления по запросу Пользователя.

4.4. Разработчик принимает разумные меры для защиты данных от несанкционированного доступа.

5. Передача данных третьим лицам

5.1. Разработчик не передаёт данные третьим лицам, за исключением случаев:

  • требования закона;
  • необходимости защиты прав и безопасности Разработчика или Пользователей.

5.2. Данные могут обрабатываться платформой Boosty в рамках оформления и проверки платной подписки. Обработка данных на стороне Boosty регулируется политикой конфиденциальности Boosty. На момент публикации данной редакции платные функции Бота временно недоступны.

6. Права пользователя

6.1. Пользователь вправе:

  • запросить информацию о том, какие данные о нём хранятся;
  • запросить удаление своих данных;
  • отозвать согласие на обработку данных.

6.2. Для реализации своих прав Пользователь может обратиться через сервер поддержки.

6.3. Запросы обрабатываются до 15 дней.

6.4. После удаления данных Пользователь может продолжать использовать Бота. При следующем взаимодействии с Ботом данные будут записаны заново. При этом предыдущий прогресс (уровень, валюта, предметы) не восстанавливается, поскольку был удалён вместе с данными.

7. Возрастные ограничения

7.1. Бот не предназначен для лиц младше 13 лет (или иного минимального возраста, установленного Discord для вашего региона).

8. Изменения Политики

8.1. Разработчик вправе изменять настоящую Политику.

8.2. Актуальная версия всегда доступна на этой странице.

8.3. Продолжение использования Бота после изменений означает согласие с новой редакцией Политики.

9. Контакты

9.1. По вопросам, связанным с обработкой данных, Пользователь может обратиться на сервер поддержки.
